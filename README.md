# Application de Gestion de Produits et Commandes - Backend

## Présentation du Projet

Ce projet est une application backend développée avec Spring Boot pour gérer des produits et des commandes. Il inclut un système d'authentification sécurisé avec JWT et Spring Security, ainsi qu'une base de données H2 pour le développement. L'objectif est de fournir une API REST sécurisée pour une application fullstack.

## Technologies Utilisées

- **Langage** : Java 17
- **Framework** : Spring Boot 3.4.1
- **Base de données** : H2 (en mémoire)
- **Sécurité** : Spring Security, JWT (JSON Web Token)
- **Gestion des dépendances** : Maven
- **Documentation API** : Swagger
